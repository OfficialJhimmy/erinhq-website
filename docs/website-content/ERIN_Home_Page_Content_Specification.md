Content, UX messaging, SEO direction and implementation notes for Claude Code

## 1. Purpose of This Page
The Home page is the main entry point for the ERIN personal brand. It should position Feyijimi Erinle as an AI Engineer and Software Engineer who builds intelligent systems, AI-powered products, automation workflows and scalable software for organisations globally.
The page should feel like a senior engineer's commercial portfolio, not a generic developer portfolio and not a typical AI agency website. The visitor should quickly understand what ERIN builds, who it is for, see evidence of the work, and have a clear path to start a conversation.

## 7. Hero Visual Direction
The visual should communicate systems thinking rather than generic AI imagery. Avoid robots, glowing brains, humanoid AI illustrations, stock AI imagery and overly futuristic graphics.
Recommended visual direction:
- A clean interactive system map showing AI agents, business systems, data, tools and human approval working together.
- Subtle animated nodes or workflow connections.
- Small examples of real system components such as Knowledge Base, CRM, WhatsApp, API, Database, AI Agent and Human Review.
- The visual should feel technical, premium and restrained.
- Animation must respect prefers-reduced-motion and must not negatively affect page performance.
## 8. Trust / Credibility Strip

## 20. Homepage UX Requirements
- The visitor should understand what ERIN does within the first 5 seconds.
- AI Solutions should be reachable from the hero without scrolling.
- Do not make the homepage feel like an AI agency template.
- Keep the copy conversational, confident and specific.
- Avoid buzzword-heavy paragraphs.
- Avoid unsupported claims, fake client logos, fake metrics or fabricated outcomes.
- Use real project screenshots, architecture diagrams and product UI wherever possible.
- Every major section should have one clear purpose and one clear CTA.
- Mobile experience must be treated as a first-class experience.
- Animations should be subtle and performance-conscious.
- Respect prefers-reduced-motion.
- Maintain strong accessibility: semantic HTML, keyboard navigation, visible focus states, sufficient contrast, alt text and correct heading hierarchy.

## 22. Content Principles for Claude Code
- Do not invent statistics, clients, testimonials, case-study outcomes or performance numbers.
- Do not describe every AI feature as an 'agent'. Use the correct technical term for the system.
- Do not make Nigeria the only target market. Nigeria is the home base; the commercial audience is global.
- Do not remove Software Engineering from the brand. It is a core differentiator and technical foundation.
- Do not use generic AI visual clichés.
- Prioritise clarity over cleverness.
- Use short paragraphs and strong headings.
- Keep CTAs action-oriented.
- Use British English.
- Never start a sentence with 'And'.
- Avoid em dashes and en dashes throughout the website copy.
